# SoundFonts

Install GeneralUser GS by running:

```bash
python scripts/install_soundfonts.py
```

The installer downloads `GeneralUser-GS.sf2` from [the author's official repository](https://github.com/mrbumpy409/GeneralUser-GS). The binary is ignored by Git.

GeneralUser GS is created by S. Christian Collins. Review its [license and documentation](https://github.com/mrbumpy409/GeneralUser-GS/tree/main/documentation) before redistributing. The author notes uncertainty about the provenance of some historical samples.

The installer uses the upstream `main` branch, so the downloaded contents may change when upstream updates. For reproducible releases, pin the upstream commit and a verified SHA-256 checksum.
